# The Void Calls — Shadow of the Stars

A roguelite space simulation prototype focused on scalable gameplay systems and modular architecture.

Inspired by the depth and freedom of space simulation games, this project explores how complex mechanics can emerge from clean, extensible systems.

---

## 🚀 Project Status

Early-stage prototype.
Core gameplay mechanics are being developed and tested independently with scalability in mind.

The primary goal of this project is to experiment with systemic design and maintainable architecture while building engaging gameplay foundations.

---

## 🎮 Gameplay Direction

* Roguelite progression
* Modular ship systems
* Expandable weapon mechanics
* Dynamic combat interactions
* System-driven gameplay logic

The design emphasizes mechanics that interact naturally, allowing unexpected but coherent gameplay outcomes.

---

## 🧠 Architectural Focus

This prototype prioritizes:

* System-based design
* Clear separation of responsibilities
* Modular and extensible gameplay components
* Scalable weapon and ship systems
* Maintainable code structure

The architecture is designed to evolve as the project grows.

---

## 🛠 Technical Highlights

* Custom lightweight dependency management
* Centralized gameplay orchestration
* Strategy-based weapon behaviors
* Object pooling for runtime stability
* Domain-oriented project structure

---

## 📌 Future Direction

* Expanded progression systems
* Deeper simulation layers
* Additional combat mechanics
* Continued architectural refinement
